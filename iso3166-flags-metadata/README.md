# Metadata files for the iso3166-flags repository

This directory contains machine-readable metadata files for the ISO 3166-1 and ISO 3166-2 flag datasets.

---

## Files

### `iso3166_flags_metadata.json`

Top-level repository statistics. Updated by running `scripts/update_everything.py`.

| Field | Type | Description |
|---|---|---|
| `total` | int | Total number of flag files across ISO 3166-1 and ISO 3166-2 |
| `iso3166_1_total` | int | Number of ISO 3166-1 country/territorial flags |
| `iso3166_2_total` | int | Number of ISO 3166-2 subdivision flags |
| `svg` | int | Total count of SVG-format flags |
| `png` | int | Total count of PNG-format flags |
| `jpg/jpeg` | int | Total count of JPG/JPEG-format flags |
| `other` | int | Count of flags in any other format |
| `duplicates` | int | Count of flags with duplicate base names across extensions |
| `duplicate_list` | list | List of duplicate filenames |
| `subdivisions_other` | list | Subdivision codes using non-standard formats |
| `total_repo_size` | string | Combined size of all flag files (KB) |
| `iso3166_1_flags_size` | string | Size of the ISO 3166-1 flags folder (KB) |
| `iso3166_2_flags_size` | string | Size of the ISO 3166-2 flags folder (KB) |
| `average_flag_size` | string | Mean file size across all flags (KB) |
| `missing_iso3166_1_count` | int | Number of ISO 3166-1 codes without a flag file |
| `missing_iso3166_2_count` | int | Number of ISO 3166-2 codes without a flag file |

---

### `iso3166_1_flag_metadata.csv`

Per-flag metadata for all ISO 3166-1 country/territorial flags. Generated by `scripts/get_flag_metadata.py`.

| Column | Description |
|---|---|
| `country_code` | ISO 3166-1 alpha-2 code (lowercase), e.g. `gb` |
| `file_name` | Filename including extension, e.g. `gb.svg` |
| `file_size_kb` | File size in kilobytes, rounded to 3 decimal places |
| `file_extension` | Uppercase file format: `SVG`, `PNG`, `JPG`, etc. |
| `dimensions` | `(height, width)` tuple in pixels |
| `aspect_ratio` | Width ÷ height, rounded to 2 decimal places |
| `flag_type` | Classification: `flag`, `coat_of_arms`, `banner`, `seal`, or `None` if unclassified |
| `quality` | Quality proxy score 0–100. For SVGs: count of vector drawing elements; for rasters: Laplacian variance |
| `source_url` | Source URL where the flag was obtained (empty if not yet recorded) |
| `dominant_colours` | Comma-separated unique fill colour hex/rgb values extracted from SVG `fill` attributes |

---

### `iso3166_2_flag_metadata.csv`

Per-flag metadata for all ISO 3166-2 subdivision flags. Same schema as `iso3166_1_flag_metadata.csv` except:

| Column | Description |
|---|---|
| `subdivision_code` | ISO 3166-2 code in standard format, e.g. `GB-SCT` |

All other columns are identical to `iso3166_1_flag_metadata.csv`.

---

### `iso3166_flag_notes.csv`

Free-text notes appended to each country's subdivision README file in `/iso3166-2-flags`. Used by `scripts/generate_readme.py` to add context about unusual flag situations (e.g. disputed territories, unrecognised flags, historical flags).

| Column | Description |
|---|---|
| `countryCode` | ISO 3166-1 alpha-2 code of the country |
| `notes` | Free-text notes to append to that country's README |

---

## Regenerating metadata

Run from the repository root:

```bash
# Regenerate all metadata, CSS, and README files in one pass
python3 scripts/update_everything.py

# Regenerate flag metadata CSVs only
python3 scripts/get_flag_metadata.py --flag_folder iso3166-1-flags --flag_metadata_output iso3166-flags-metadata/iso3166_1_flag_metadata.csv
python3 scripts/get_flag_metadata.py --flag_folder iso3166-2-flags --flag_metadata_output iso3166-flags-metadata/iso3166_2_flag_metadata.csv

# Preview changes without writing to real files (dry run)
python3 scripts/update_everything.py --dry-run

# Check whether the committed CSS/README/metadata files are stale relative to the flag directories,
# without modifying anything - exits non-zero if anything is stale (used as a CI gate)
python3 scripts/update_everything.py --check
```
